# Color to use in the UI/UX of the application

The UI of this software is based on the Vuetify framework (based on Material Design).

The goal of `Woodstock Backup` is to backup devices on a central computer. The pool storage is composed of chunks. The name of the software was inspired by the Woodstock festival, but can be used as a reference to a storage of wood.

The color scheme of the software is based on the colors of wood.
